# SpecialMe website

Static launch page for specialme.app, published with GitHub Pages from the `main` branch.

- `index.html` is the whole site. The sign-up form saves to the `trial_signups` table in the `specialme-website` Supabase project (public insert only).
- `CNAME` holds the custom domain.
- Do not add anything private to this repository. It is public.
